## 🚀 특징

- 5개 카테고리로 정리된 66종 미니게임
- 모바일과 데스크톱을 모두 고려한 반응형 UI
- 순수 HTML/CSS/JavaScript 기반의 가벼운 구성
- 설치 없이 브라우저에서 바로 실행 가능

## 🎮 플레이 방법

### 로컬에서 실행
```bash
# 저장소 클론
git clone https://github.com/juhee77/simple_game.git
cd simple_game

# 간단한 HTTP 서버 실행
python3 -m http.server 8000

# 브라우저에서 http://localhost:8000 접속
```

## 🎨 게임별 특징

대표 게임 예시:

- `2048`: 점수/최고 점수 저장, 키보드/스와이프 조작
- `슬라이딩 퍼즐`: 3x3, 4x4, 5x5 퍼즐과 베스트 기록 저장
- `가짜 취향 감별기`: 폰을 넘기며 역할 확인, 답변 공개 후 가짜 추리
- `침묵 경매`: 최저 단어 수 입찰 후 설명 도전, 라운드별 점수 집계
- `한 글자씩 망가뜨리기`: 한 턴에 한 글자만 추가/삭제/교체하는 폰 넘기기 언어유희
- `거짓말 증폭기`: 한 줄씩 덧붙이며 말투 미션에 맞춰 이야기를 증폭
- `동시 배신 게임`: 라운드마다 바뀌는 규칙에 맞춰 비밀 행동을 선택하는 심리전
- `합계 100 만들기`: 비밀 숫자 손패를 관리하며 100에 가장 가깝게 맞추는 경쟁 게임
- `블러프 좌표 사냥`: 진짜 힌트와 가짜 힌트 사이에서 좌표와 정보원을 함께 추리
- `기억 오염 실험`: 첫 장면이 사람을 거치며 얼마나 왜곡되는지 비교하는 릴레이 실험
- `지뢰찾기`: 난이도 선택, 타이머, 깃발 표시
- `스도쿠`: 퍼즐 생성, 힌트, 유효성 검사
- `태양계`: 3D 우주 시뮬레이션
- `네온 터널 러너`: 거리 기반 회피 액션
- `플루이드 아트`: 시각 중심 인터랙티브 경험
- `릴레이 드로잉`: 폰 넘기기 기반 파티 플레이

### 네온 크라임씬
- 4~6인 역할극 추리 게임
- 알리바이와 단서 제공
- 토론 및 투표 시스템
- 동적 시나리오 역할 분담

### 프로젝트 레테 (Project Lethe)
- 2인 비대칭 협동 게임 (폭탄 해체 스타일)
- 현장 요원(다이버)과 본부 요원(오퍼레이터)의 화면 및 역할 분리
- 3가지 해킹 퍼즐과 긴박한 5분 타이머

### 그림자 상단 (The Shadow Syndicate)
- 1920년대 느와르 테마의 2인 핫시트 드래프팅 대결
- 피라미드 형태의 비밀의 거미줄 카드 시스템
- 무력, 경제 독점, 영향력 점수 등 3가지 승리 조건 탑재

### 별빛 조율사 (Starlight Tuners)
- 우주 감성 폴리오미노(조각보) 타일 놓기 게임
- 뒤쳐진 사람이 턴을 갖는 궤도(Orbit) 트랙 시스템
- 별가루 수입 정산과 타일 회전 배치 퍼즐

### 초성 퀴즈 (Initial Consonant Quiz)
- 영화/드라마, K-Pop/음악, 음식/디저트, 속담, 일상/동물 등 5가지 풍부한 카테고리
- 제한 시간 타이머와 점수 계산용 실시간 스코어보드 탑재
- 남녀노소 누구나 즉석에서 정답을 외치며 즐기는 예능형 파티 게임

### 밸런스 게임 (Balance Game)
- 일반 모드(가벼운 논쟁), 매운맛 토론 모드(과몰입 유발), 커플 전용 모드(연애관 딥톡) 지원
- 외모 vs 성격, 연락 주기, 깻잎 논쟁, 기념일 등 극적이고 구체적인 시나리오 데이터베이스 탑재
- 모바일 화면 분할 최적화 및 유려한 애니메이션 피드백 선사

### 무작위 팀 나누기 (Team Splitter)
- 단체방 공지나 카카오톡 명단 등을 복사해서 붙여넣기만 하면 무작위로 조를 편성해주는 최적화된 입력기 탑재
- '총 N개 팀으로 구성' 및 '한 팀당 N명씩 구성'의 2대 분할 방식 제공
- 웃기거나 유니크한 팀 이름(예: 상큼발랄 레몬 에이드, 벼락치기 천재단 등)을 무작위로 매칭시켜주는 재미 요소 제공
- 이름들이 무작위로 회전하며 매칭되는 세련된 셔플 애니메이션 연출
- 편성 결과를 간편하게 단톡방에 올릴 수 있도록 클립보드 복사(📋) 기능 지원
