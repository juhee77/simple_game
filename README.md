# 🎮 미니게임 천국 (Mini Game Paradise)

**98가지 미니게임**을 6개 카테고리별로 즐길 수 있는 웹 게임 포털입니다.  
설치 없이 브라우저에서 바로 플레이! 모바일 · 데스크톱 모두 지원합니다.

> 🌐 **[지금 바로 플레이하기 →](https://juhee77.github.io/simple_game/)**

## 🎮 플레이 방법

### GitHub Pages에서 바로 플레이
👉 [https://juhee77.github.io/simple_game/](https://juhee77.github.io/simple_game/)

### 로컬에서 실행
```bash
# 저장소 클론
git clone https://github.com/juhee77/simple_game.git
cd simple_game

# 간단한 HTTP 서버 실행
python3 -m http.server 8000

# 브라우저에서 http://localhost:8000 접속
```

## 🎨 주요 게임 하이라이트

### 🕵️ 네온 크라임씬
- 역할극 추리 게임, 시나리오 8편 (4~7명)
- **자동 진행 모드**: 앱이 단계·시간·대사를 안내해 GM 없이도 플레이 가능
- 4인 전용 시나리오 「폐업 전야의 레코드숍」 수록

### 🐺 한밤의 늑대인간
- 사회자 없는 단판 마피아
- 앱이 밤 단계를 자동으로 진행, 폰을 넘기며 역할 수행

### ☕ 골목 카페 운영기
- 30일 경영 시뮬레이션 (1인)
- 메뉴 가격·설비 투자·임대 재계약 등 전략적 경영 판단

### 🏒 네온 에어하키
- 실시간 1대1 터치/마우스 대전
- 물리 엔진 기반 퍽 반사 시스템

### ⌨️ 타이핑 레이서
- 유령 기록과 경주하는 타이핑 게임
- 최고 기록 갱신 도전

### 🔄 리버시
- AI 3단계 (초급/중급/고급) 대전
- 클래식 오셀로 규칙

### 🏰 네온 타워 디펜스
- 웨이브 방어 전략 게임
- 타워 배치 · 업그레이드 시스템

### 🎯 한글 워들
- 매일 바뀌는 두 글자 한국어 추론
- 자음/모음 힌트 시스템

### 📦 창고지기
- 12단계 상자 밀기 클래식 퍼즐
- 되돌리기 기능 지원

### 🗣️ 네온 잰말놀이
- 엄선된 한국어 잰말놀이 100선 (쉬움/보통/어려움)
- ♾️ 무한 도전 모드: 실패할 때까지 계속 도전
