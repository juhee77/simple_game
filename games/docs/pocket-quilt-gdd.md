# 🧵 포켓 퀼트 (Pocket Quilt) - 기획서 (GDD)

이 게임은 기존 모바일 '패치워크'의 불편한 조작감과 복잡한 UI를 모바일(핫시트)에 완벽하게 최적화한 **2인용 타일 배치 전략 게임**입니다.

---

## 1. 📝 게임 개요
* **장르**: 폴리오미노(테트리스 블록) 배치 및 자원 관리
* **대상 인원**: 2인 (핫시트 방식)
* **목표**: 7x7 보드판에 퀼트 조각을 배치하여 빈칸을 최소화하고 단추(점수)를 가장 많이 모으는 것.
* **플레이 타임**: 약 10~15분

---

## 2. ⚙️ 핵심 게임 시스템 (Core Loop)

### 🕹️ 모바일 최적화 조작
* **스마트 호버링**: 조각을 드래그할 때 손가락 위로 블록이 떠올라(Offset), 내가 놓을 위치가 손가락에 가려지지 않습니다.
* **오토 스냅 (Auto Snap)**: 7x7 그리드 근처에 가져가면 블록이 제자리에 찰칵 달라붙습니다.
* **원터치 회전**: 드래그 중인 상태가 아닐 때, 조각을 '터치(Tap)'하면 자동으로 90도 회전합니다. 복잡한 회전 버튼이 필요 없습니다.

### ⏳ 시간과 단추 (Time & Button Economy)
* **재화**: '단추'는 조각을 사는 돈이자 최종 점수입니다. '시간'은 조각을 샀을 때 타임 트랙에서 전진하는 칸 수입니다.
* **턴 진행**: 항상 타임 트랙에서 **'뒤에 있는 사람'**이 턴을 진행합니다. 만약 뒤에 있던 사람이 조각을 샀는데 여전히 상대보다 뒤에 있다면 연속으로 턴을 진행합니다.
* **조각 구매**: 매 턴 하단에 3개의 조각이 제시됩니다. 단추가 충분하다면 조각을 구매하여 7x7 보드에 배치할 수 있습니다.
* **단추 수입**: 타임 트랙에 있는 '결산선'을 지나갈 때마다, 내 보드에 배치된 조각들에 그려진 단추 개수만큼 단추를 받습니다.
* **패스 (전진)**: 살 조각이 없거나 전략적으로 패스할 경우, 상대방 말의 바로 앞 칸까지 전진하고 이동한 칸 수만큼 단추를 얻습니다.

---

## 3. 🎨 화면 구성 (Layout)

1. **상단 (Top)**: 
   - 일자형(선형) 타임 트랙 바. 두 플레이어의 말 위치와 결산선 위치가 표시됩니다.
   - 상대방의 요약 정보 (미니맵 보드, 보유 단추 수).
2. **중앙 (Center)**:
   - 현재 턴인 플레이어의 거대한 7x7 퀼트 보드판.
3. **하단 (Bottom)**:
   - 구매 가능한 3개의 퀼트 조각과 가격/시간/수입 정보.
   - '패스하고 단추 얻기' 버튼.

---

## 4. 🛠️ 기술적 구현 포인트
* **2D Array 그리드 검사**: 테트리스 블록 형태의 2차원 배열을 7x7 보드에 겹치지 않게 놓을 수 있는지 검증.
* **드래그 앤 드롭 API**: 모바일의 `touchstart`, `touchmove`, `touchend` 이벤트를 정교하게 제어하여 호버링 오프셋 적용.
* **자동 스왑 애니메이션**: 턴이 넘어갈 때 "Player 2 기기를 넘겨주세요" 화면과 함께 보드의 색상과 데이터가 매끄럽게 교체됨.
