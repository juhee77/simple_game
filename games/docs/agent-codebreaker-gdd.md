# 🕵️‍♂️ 게임 기획서: 첩보원 - 암호 해독 (Agent: Codebreaker)

## 1. 게임 개요
* **장르**: 2인 협동 단어 연상 추리 게임
* **모티브**: 코드네임 듀엣 (Codenames Duet)
* **플레이 인원**: 2인 (핫시트 또는 화면 공유)
* **목표**: 제한된 턴 안에 25개의 단어 중 15명의 '아군 요원'을 모두 찾아내야 합니다. 암살자를 선택하면 즉시 게임오버 됩니다.

## 2. 세계관 및 테마
당신과 파트너는 적진 깊숙이 고립된 특수 요원입니다. 아군의 구출을 위해 연락망에 있는 다른 요원들과 접선해야 합니다. 하지만 통신 채널이 감청당하고 있어, 서로에게 전할 수 있는 정보는 오직 **"단 하나의 단어와 숫자"**뿐입니다.

## 3. 핵심 구성 요소
1. **단어 그리드 (5x5)**: 무작위 명사 25개가 배치된 보드판.
2. **정답 지도 (Key Card)**: 플레이어 1(P1)과 플레이어 2(P2)는 서로 다른 정답 지도를 봅니다.
   - **아군 요원 (초록색, 9개)**: 반드시 찾아야 하는 대상. (P1과 P2가 보는 아군 중 3개는 겹칩니다. 따라서 총 15개의 아군이 존재합니다.)
   - **민간인 (살구색)**: 잘못된 단어. 선택 시 턴이 즉시 종료됩니다.
   - **암살자 (검은색, 3개)**: 절대 선택해서는 안 되는 단어. 선택 시 즉시 패배합니다. (P1의 암살자는 P2에게 민간인/아군일 수 있습니다.)
3. **타이머 / 턴 마커**: 총 9번의 턴(기회)이 주어집니다. 9번의 힌트 안에 15명의 요원을 모두 찾아야 합니다.

## 4. 플레이 진행 (Core Loop)
게임은 P1과 P2가 번갈아 가며 힌트를 주는 방식으로 진행됩니다.

### [Phase 1: 힌트 주기]
1. 턴을 맞은 플레이어(힌트 제공자)는 자신의 정답 지도를 확인합니다.
2. 여러 개의 초록색(아군) 단어를 동시에 설명할 수 있는 **하나의 연관 단어**를 떠올립니다.
3. 상대방에게 **단어 1개와 숫자 1개**를 말해줍니다.
   > 예시: 정답 지도에 `사과`, `바나나`, `원숭이`가 초록색이라면, **"노란색, 2"** 라고 힌트를 줄 수 있습니다. (`바나나`, `원숭이`를 노린 힌트)

### [Phase 2: 추리 및 선택]
1. 상대방(추리자)은 힌트를 듣고 25개의 단어 중 정답이라 생각하는 단어를 **하나씩 클릭**합니다.
2. 클릭 결과에 따라 다음과 같이 처리됩니다:
   * **초록색 (아군)**: 정답! 계속해서 다른 단어를 클릭하거나, 추리를 멈추고 턴을 종료할 수 있습니다.
   * **살구색 (민간인)**: 오답! 즉시 추리가 종료되고 다음 사람의 턴으로 넘어갑니다. 턴 마커가 1개 소비됩니다.
   * **검은색 (암살자)**: 치명적 오답! **즉시 게임 패배**로 끝납니다.

## 5. 승리/패배 조건
* **승리**: 9턴이 끝나기 전에 15개의 아군 요원 타일을 모두 찾아내면 승리! (P1 화면과 P2 화면 양쪽에서 모두 초록색 불이 들어온 상태가 됩니다.)
* **패배**: 
  1. 누군가 '암살자' 단어를 클릭했을 때.
  2. 15개의 아군 요원을 모두 찾지 못했는데 9번의 턴이 모두 끝났을 때.

## 6. UI / UX 설계 포인트
* **직관적인 타일 디자인**: 단어 타일은 깔끔한 버튼 형태로 디자인하며, 클릭 시 부드럽게 뒤집히면서(CSS 3D Flip) 정답 색상이 드러나도록 연출합니다.
* **비밀 지도 보기 기능**: 힌트를 주는 사람은 '내 정답 지도 보기' 버튼을 꾹 누르고 있는 동안에만 정답 색상이 타일에 오버레이되어 보이도록 하여, 부정행위를 방지하고 긴장감을 높입니다.
* **사운드 피드백**: 아군(띠링!), 민간인(띡-), 암살자(쾅!) 사운드를 다르게 배치하여 청각적 피드백을 강화합니다.
* **기획서 뷰어**: 우측 상단 돋보기(🔍) 아이콘 클릭 시, 지금 보시는 이 기획 문서(GDD)가 깔끔한 모달 창으로 렌더링되어 표시됩니다.
