# 🧠 프로젝트 레테 (Project Lethe) 기획서

## 1. 게임 개요
* **장르**: 2인 비대칭 협동 퍼즐 (사이버펑크 스릴러)
* **목표**: 제한 시간 5분 안에 3개의 '기억 복원 모듈'을 해제하여 대상자의 뇌신경(시냅스) 붕괴를 막는 것.
* **플레이 인원**: 2명 (기기 2대 권장, 음성 통화 필수)

## 2. 역할 (Roles)
### 2.1 다이버 (Diver)
* **설정**: 환자의 뇌신경망에 직접 다이브하여 붕괴하는 시냅스를 물리적으로 재연결하는 현장 요원.
* **시야**: 직관적이고 복잡한 퍼즐 UI(슬라이더, 심볼, 키패드)를 보며 직접 조작합니다.
* **제약**: 퍼즐을 푸는 규칙(정답)은 전혀 알 수 없습니다. 오퍼레이터에게 자신이 보는 것을 정확히 묘사해야 합니다.

### 2.2 오퍼레이터 (Operator)
* **설정**: 현실 세계의 의료 통제실에서 구형 신경망 해킹 매뉴얼을 보며 다이버를 서포트하는 요원.
* **시야**: 화면 조작 버튼이 전혀 없습니다. 오직 복잡한 텍스트와 조건문으로 이루어진 '방화벽 해제 매뉴얼'만 봅니다.
* **제약**: 다이버가 어떤 상황인지 볼 수 없습니다. 다이버의 설명을 듣고 매뉴얼을 뒤져 정답을 지시해야 합니다.

## 3. 핵심 시스템
* **타이머**: 5분. 시간이 다 되면 환자의 기억이 삭제되며 게임 오버.
* **스트라이크 (시냅스 충격)**: 잘못된 조작을 할 때마다 시냅스 충격이 누적됩니다. 3회 누적 시 즉시 게임 오버.
* **승리 조건**: 3개의 모듈을 모두 초록색(해제 상태)으로 만들기.

## 4. 퍼즐 모듈 기획 (Modules)

### 모듈 1: 시냅스 주파수 정렬 (Sliders)
* **다이버 시점**: 빨강, 파랑, 노랑, 초록색의 슬라이더 4개가 있습니다. 각 슬라이더는 1부터 5까지 조절 가능합니다. 상단에 환자 ID(예: #8492)가 무작위로 적혀 있습니다.
* **오퍼레이터 매뉴얼**: 
  - "환자 ID의 마지막 자리가 홀수라면: 빨강을 3에, 파랑을 1에 맞추시오."
  - "환자 ID의 마지막 자리가 짝수라면: 초록을 노랑보다 정확히 2단계 높게 맞추시오. 단, 빨강은 무조건 5여야 합니다."

### 모듈 2: 기억 파편 방화벽 (Symbols)
* **다이버 시점**: 기하학적 심볼(예: 👁️, ⚙️, ⚡, 💠, 🔺) 4개가 일렬로 나열된 패널이 있습니다. 아래에는 누를 수 있는 빈 버튼 4개가 있습니다.
* **오퍼레이터 매뉴얼**: 
  - (심볼들의 우선순위 표 존재)
  - "만약 패널에 ⚡ 심볼이 있다면, 가장 먼저 ⚡를 누르시오."
  - "그렇지 않고 ⚙️ 심볼이 2개 이상 있다면, 두 번째 심볼을 누르시오."
  - "해당하는 조건이 없다면, 마지막 심볼을 누르시오."
  - (이를 4번 반복하여 모든 심볼을 정확한 순서로 눌러야 해제됨)

### 모듈 3: 코어 오버라이드 (Button Timing)
* **다이버 시점**: 커다란 버튼 하나가 있습니다. 버튼에는 '추출(EXTRACT)' 또는 '폐기(DUMP)'라는 글자가 적혀 있고, 버튼 색상은 빨강, 파랑, 하양 중 하나입니다. 버튼 우측에는 카운트다운 타이머(초 단위)가 보입니다.
* **오퍼레이터 매뉴얼**:
  - 1단계: 버튼 누르는 방식 결정
    - 버튼이 파란색이고 '추출'이라고 적혀 있다면: "즉시 클릭하고 떼시오."
    - 버튼이 빨간색이라면: "버튼을 꾹 누른 채로 유지하시오."
  - 2단계: 꾹 누르고 있을 때 떼는 타이밍
    - (다이버가 버튼을 꾹 누르면 버튼 옆에 노란색 불빛이 켜짐)
    - "버튼 옆 불빛이 노란색이라면, 타이머의 초 단위에 '5'가 들어갈 때(예: 45초, 05초) 떼시오."

## 5. UI/UX 디자인 방향
* **다이버**: 네온 사인, 어두운 배경, 글리치(Glitch) 효과. 긴박한 사이버펑크 분위기.
* **오퍼레이터**: 녹색 텍스트 터미널 느낌 또는 낡은 기밀문서 느낌. 스크롤을 내리며 규칙을 찾아야 하는 방대한 텍스트.
* **공통**: 화면 우측 상단에 돋보기 아이콘 🔍을 배치하여 언제든 이 기획서(GDD) 원본을 열람할 수 있도록 구현.
