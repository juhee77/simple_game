# 🎨 디자인 시스템

> **기준: `styles/game-common.css`의 `:root` 블록**
> 새 게임을 만들 때 색·반경을 새로 찍지 말고 여기 있는 토큰을 `var()`로 참조하세요.

---

## 왜 정리했나

게임이 97종으로 늘어나는 동안 각 게임이 자기 `:root`에 색을 새로 선언해 왔습니다.
정리 전 실측치는 이랬습니다.

| 항목 | 정리 전 |
|---|---|
| 자기 `:root`를 가진 게임 | 97개 중 43개 |
| 같은 `--bg`의 서로 다른 값 | 20가지 |
| 같은 `--panel`의 서로 다른 값 | 16가지 |
| 같은 `--border`의 서로 다른 값 | 14가지 |
| `border-radius` 값 종류 | 28가지 (634회 사용) |

게임을 하나 만들 때마다 색을 새로 고민해야 했고, 그러다 보니 포털 전체 톤이
조금씩 어긋나 있었습니다.

---

## 토큰 두 벌이 있는 이유

`game-common.css`에는 토큰이 두 묶음 있습니다. **둘 다 유효하며, 섞어 쓰지 마세요.**

### ① 기존 토큰 — 값 변경 금지

`--bg-primary` `--bg-secondary` `--bg-card` `--accent-primary` `--accent-secondary`
`--accent-tertiary` `--text-primary` `--text-secondary` `--text-muted` `--border-color`
`--success` `--warning` `--danger`

**35개 게임이 이미 참조 중**입니다. 값을 바꾸면 그 게임들의 외관이 한꺼번에 바뀌므로
건드리지 않습니다. (2048, 지뢰찾기, 스도쿠, 사다리, 룰렛, 초성 퀴즈 등)

### ② 표준 토큰 — 새 게임은 이쪽

```css
--bg      : #0f172a                     /* 페이지 배경 */
--panel   : rgba(255, 255, 255, .05)    /* 카드·패널 배경 */
--border  : rgba(255, 255, 255, .14)    /* 테두리 */
--text    : #f8fafc                     /* 본문 글자 */
--muted   : #94a3b8                     /* 보조 설명 글자 */
--accent  : #38bdf8                     /* 강조 (게임마다 덮어쓰는 편) */

--ok      : #4ade80                     /* 성공·정답 */
--warn    : #fbbf24                     /* 주의 */
--bad     : #f87171                     /* 실패·오답 */

--r-sm    : 8px      /* 작은 버튼·태그 */
--r-md    : 14px     /* 입력창·타일 */
--r-lg    : 20px     /* 카드 */
--r-pill  : 999px    /* 알약 버튼 */

--gap-xs  : 6px
--gap-sm  : 10px
--gap-md  : 14px
--gap-lg  : 20px
```

이 값들은 임의로 고른 게 아니라 **기존 게임에서 가장 많이 쓰이던 값**을 그대로
표준으로 삼은 것입니다. (`#f8fafc` 28회, `#94a3b8` 17회, `#0f172a` 13회 등)

---

## 게임 고유 테마는 덮어쓰세요

분위기가 중요한 게임은 자기 `:root`에서 필요한 토큰만 재정의합니다.
**전부 다시 선언하지 말고, 바꿀 것만 덮어쓰는 것이 요령입니다.**

```css
/* 좋은 예 — 늑대인간: 밤 분위기라 배경만 바꾼다 */
:root {
    --bg: #0c0a1a;
    --wolf: #f87171;
    --village: #4ade80;
}
```

현재 의도적으로 테마를 쓰는 게임들입니다. 이들은 정리 대상이 아닙니다.

| 게임 | 테마 |
|---|---|
| 한밤의 늑대인간 | 밤 보라 `#0c0a1a` |
| 마니또 뽑기 | 숲 초록 `#0d1a14` |
| 오늘의 운세 | 신비 보라 `#14091f` |
| 관제실 탈출 | 관제 청색 `#060d16` |
| 그림자 상단 | 느와르 갈색 `#1a1512` |
| 별빛 조율사 | 우주 흑청 `#090a0f` |
| 텔레파시 스케치 | 밝은 배경 `#F7FFF7` |

## 새 게임 만들 때

1. `<head>`에 공용 자산을 링크합니다. 순서를 지키세요 — 공용 스크립트가 인라인
   스크립트보다 **먼저** 와야 `loadBestRecord` 같은 헬퍼를 초기 렌더에서 쓸 수 있습니다.

   ```html
   <script src="../scripts/game-common.js"></script>
   <link rel="stylesheet" href="../styles/game-common.css">
   ```

2. 색은 `var(--bg)` 처럼 토큰으로 씁니다. 테마가 필요하면 자기 `:root`에서 덮어씁니다.

3. 파일을 저장한 뒤 **반드시** 버전 스탬프를 갱신합니다.

   ```bash
   node scripts/stamp-assets.mjs
   ```

   공용 자산과 HTML은 짝을 이루기 때문에, 이걸 빼먹으면 브라우저가 옛 자산을
   캐시에서 꺼내 써서 기능이 통째로 죽습니다. 실제로 이 사고가 세 번 났습니다.

## 아직 남은 것

- **기존 토큰과 표준 토큰의 배경색이 다릅니다.** `--bg-primary`는 `#0a0e27`,
  `--bg`는 `#0f172a`입니다. 둘 다 아주 어두운 남색이라 나란히 놓기 전에는
  차이를 알기 어렵지만, 엄밀히는 두 계열이 공존하는 상태입니다.
  통일하려면 35개 게임의 외관이 미세하게 바뀌므로 별도 판단이 필요합니다.
- **`border-radius`는 아직 대부분 하드코딩**입니다. 토큰(`--r-*`)은 만들어 뒀으니
  게임을 손볼 때마다 조금씩 바꿔 나가면 됩니다.
- **명도 대비는 검증하지 않았습니다.** `--muted`(#94a3b8)를 어두운 배경에 쓴 곳이
  많은데 WCAG 기준을 통과하는지 확인이 필요합니다.
