# 💣 게임 기획서: 폭탄 해체반 (Bomb Defusal Squad)

## 1. 게임 개요
* **장르**: 2인 비대칭 협동 퍼즐 게임
* **모티브**: Keep Talking and Nobody Explodes
* **플레이 인원**: 2인 (한 명은 '해체 전문가', 한 명은 '정보 전문가')
* **목표**: 제한 시간 내에 정보 전문가의 매뉴얼 설명을 듣고 해체 전문가가 폭탄의 모든 모듈을 해제해야 합니다.

## 2. 세계관 및 테마
당신은 특수 폭탄 제거반입니다. 현장에 투입된 요원(해체 전문가) 앞에는 복잡한 시한폭탄이 놓여 있고, 본부의 분석관(정보 전문가)은 폭탄의 설계도를 확보했습니다. 하지만 분석관은 폭탄을 볼 수 없고, 요원은 설계도를 볼 수 없습니다. 오직 음성 통신(대화)만으로 폭탄을 해체해야 합니다!

## 3. 핵심 구성 요소
1. **폭탄 본체 (해체 전문가 화면)**:
   - **디지털 타이머**: 남은 시간 표시. (0이 되면 폭발)
   - **스트라이크(오류) 카운터**: 실수를 3번 하면 즉시 폭발.
   - **다양한 모듈**: 전선 자르기, 버튼 순서대로 누르기, 암호 키패드 등.
2. **해체 매뉴얼 (정보 전문가 화면)**:
   - 각 모듈별 해제 규칙이 적힌 텍스트 문서. (예: "전선이 4개이고 노란색이 없으면 두 번째 선을 잘라라.")

## 4. 플레이 진행 (Core Loop)
이 게임은 두 명의 플레이어가 서로 다른 정보를 가지고 소통하는 것이 핵심입니다.

### [Phase 1: 역할 분담]
* 한 명은 **'해체 전문가'** 버튼을 눌러 폭탄 화면을 봅니다.
* 다른 한 명은 **'매뉴얼 보기'** 버튼을 눌러 규칙 문서를 봅니다. (서로의 화면을 절대 보지 않는 것이 룰입니다!)

### [Phase 2: 모듈 해체]
* 해체 전문가는 현재 보이는 모듈의 특징(선 색깔, 버튼 문구 등)을 설명합니다.
* 정보 전문가는 매뉴얼에서 해당 모듈을 찾아 해결책을 알려줍니다.
* **모듈 예시**:
  1. **전선 모듈**: 3~5개의 전선. 매뉴얼의 조건문(색상, 개수 등)에 따라 특정 전선을 클릭해 잘라야 함.
  2. **기호 버튼**: 4개의 기호 버튼. 매뉴얼에 명시된 올바른 '순서'대로 눌러야 함.
  3. **숫자 키패드**: 특정 힌트를 통해 도출된 4자리 암호를 입력해야 함.

### [Phase 3: 임무 완수]
* 모든 모듈을 초록색(해제)으로 만들면 타이머가 멈추고 게임 승리!

## 5. 승리/패배 조건
* **승리**: 제한 시간 내에 모든 모듈 해제 성공.
* **패배**:
  1. 타이머가 0이 되었을 때.
  2. 실수를 3번 하여 폭탄이 과부하되었을 때.

## 6. UI / UX 설계 포인트
* **비대칭 레이아웃**: 한 브라우저 내에서 탭을 나누거나, 화면을 절반으로 가려 다른 플레이어가 보지 못하게 유도.
* **긴박한 연출**: 시간이 30초 남으면 타이머가 빨갛게 점멸하며 심장 박동 사운드가 빨라짐.
* **모듈 디자인**: 스팀펑크 혹은 사이버펑크 느낌의 기계적인 그래픽 요소 적용.
* **기획서 뷰어**: 우측 상단 돋보기(🔍) 아이콘 클릭 시, 지금 보시는 이 기획 문서(GDD)가 표시됩니다.
